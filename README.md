# SSF Stories – Email Template Demonstration

This repository contains HTML email templates prepared using story content provided by **Shooting Stars Foundation (SSF)**.

The purpose of this repository is to demonstrate the technical implementation of donor-story email templates and how HTML email content can be prepared for use with an email platform such as **Sendy**.

## Purpose

This repository was created as a technical demonstration to help a colleague understand:

- How an SSF story can be structured as an HTML email
- How images, text, links, and styling can be arranged for email
- How an HTML email can be prepared for use in Sendy
- How static HTML email templates can be maintained and tested

This repository is **not intended to publish, distribute, or provide access to SSF's underlying stories or organizational data**.
